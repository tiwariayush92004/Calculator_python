# 🧮 Basic Python Calculator
## 🚀 Features

* **Python Backend Logic:** Performs all calculations server-side in Python.
* **Clean & Modern UI:** Simple responsive design styled with CSS.
* **Basic Operations Supported:**
  * Addition (`+`)
  * Subtraction (`-`)
  * Multiplication (`*`)
  * Division (`/`)
  * Modulo / Remainder (`%`)
  * Exponentiation / Power (`**`)
* **Error Handling:** Gracefully handles division-by-zero and invalid numerical inputs.
